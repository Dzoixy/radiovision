# Deep Learning X-ray Analysis 
ระบบวิเคราะห์ภาพเอกซเรย์ทด้วยDeep Learning เพื่อช่วยจำแนกภาพและแสดงผลลัพธ์แบบอัตโนมัติพร้อม Heatmap 
## Features
- อัปโหลดภาพเอกซเรย์ผ่านหน้าเว็บ
- วิเคราะห์ภาพด้วยโมเดล Deep Learning (CNN)
- แสดงผลการจำแนก (Classification)
- แสดงค่าความเชื่อมั่น (Confidence Score)
- แสดงภาพ Heatmap 
- สร้างรายงานผลอัตโนมัติ
##  เครื่องมือที่ใช้

### Backend
- Python
- FastAPI
- PyTorch

### Frontend
- HTML
- CSS
- JavaScript

### Image Processing
- OpenCV
- NumPy

## Workflow
1. ผู้ใช้อัปโหลดภาพเอกซเรย์
2. ระบบทำการ Preprocessing ภาพ
3. ส่งภาพเข้าโมเดล Deep Learning
4. โมเดลทำการจำแนกผลลัพธ์
5. สร้าง Heatmap และรายงาน
6. แสดงผลผ่านหน้าเว็บ
